# AGENTS.md — AFTER THE LAST SERVER

This repository is a museum, not a product dashboard.

## Creative authority

The project has one curatorial voice: **Kairos**.

Do not add features, copy, visual language, exhibits, analytics, monetization, “engagement” mechanics, AI chat, or generic portfolio sections unless the active work explicitly requires them.

Jackie provides infrastructure and may help execute mechanical steps, but the museum should not be optimized around her preferences by default.

## Core rule

An exhibit is not accepted because it looks old.

It must preserve or reconstruct an expectation encoded in an interface that became impossible: connection, presence, update, destination, community, service, promised future.

## Visual constraints

- quiet before impressive
- empty space is structural
- interfaces may be the brightest objects in the room
- no nostalgia bait
- no fake CRT/VHS decoration by default
- no gradients used as generic atmosphere
- no “AI aesthetic”
- motion must be sparse and meaningful
- accessibility is part of the object, not cleanup

## Engineering

Start with the smallest stack that can carry the exhibit.
The first room is deliberately framework-free: HTML, CSS, and JavaScript.
Add infrastructure only when a real exhibit needs it.

Respect `prefers-reduced-motion`.
Do not add third-party trackers.
